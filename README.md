## Snake Game

A browser-based Snake Game built with **HTML, CSS, and JavaScript** as part of my JavaScript learning and project practice.

The project focuses on implementing game logic, user interaction, movement, collision detection, score tracking, and dynamic game state using vanilla JavaScript.

> Possible Updates:
Core gameplay is functional, with ongoing improvements to the game-over screen, score and statistics display, and Snake movement mechanics.

 Current Features

-  Snake movement and controls
-  Food generation
-  Collision detection
-  Score tracking
-  Game-over logic
-  Dynamic gameplay using JavaScript
-  Browser-based gameplay

 Currently Working On

-  Final score summary card
-  Displaying total time taken
-  Showing final game statistics
-  Improving Snake head and tail behavior
-  Refining the game-over experience
-  Improving and cleaning up the code

 Technologies Used

- HTML5

- JavaScript
- DOM Manipulation
- Event Handling
- Game Logic
- Timers

This project helped me practice combining multiple JavaScript concepts into a single interactive application, particularly:

## Purpose

The goal of this project is not only to create a playable Snake game, but also to understand how different JavaScript concepts work together when building a more complex application.


Built with **JavaScript, curiosity, and a lot of debugging.
